## 2. ما لا يُسجَّل مطلقاً

كلمات المرور · رموز الاستعادة والتحقق · معرّفات الجلسات · بيانات الحسابات البنكية
· الرقم القومي · أي بيانات شخصية غير ضرورية.

التنقيح مركزي في `Logger::redact()` و`AuditLogger::redact()` — لا يعتمد على انضباط
كل مُستدعٍ.

## 3. رفع الملفات (البنية جاهزة، التفعيل في المرحلة الثانية)

- التخزين في `storage/uploads` **خارج جذر الويب**.
- التحقق بالامتداد **و** نوع MIME الحقيقي (`finfo`) **و** الحجم.
- قائمة امتدادات ممنوعة دائماً (`php`, `phtml`, `svg`, `html`…).
- أسماء ملفات عشوائية عند التخزين.
- إعادة ترميز الصور لإزالة أي حمولة مدسوسة.
- التقديم عبر متحكّم يتحقق من الملكية ويسجّل التنزيل.

## 4. قائمة مراجعة ما قبل الإنتاج

- [ ] `APP_ENV=production` و`APP_DEBUG=false`
- [ ] `APP_KEY` مُولَّد وفريد لكل بيئة
- [ ] `SESSION_SECURE=true` و`HSTS_ENABLED=true` بعد تفعيل HTTPS
- [ ] كلمات مرور قاعدة البيانات قوية ومستخدم بأقل صلاحية (لا `root`)
- [ ] جذر الموقع يشير إلى `public/` فقط
- [ ] صلاحيات الملفات: `640` للملفات، `750` للمجلدات، `600` لـ `.env`
- [ ] `storage/` قابل للكتابة من مستخدم الويب فقط
- [ ] حذف بذور العرض التوضيحي (`php bin/console health` يتحقق من الإعدادات)
- [ ] تغيير كل كلمات مرور الحسابات التجريبية أو حذفها
- [ ] تفعيل النسخ الاحتياطي المجدول واختبار الاسترجاع فعلياً
- [ ] تدوير السجلات مُفعَّل
- [ ] مراجعة قانونية لنصوص الشروط وسياسة الخصوصية
- [ ] `php bin/console health` يمرّ بالكامل
- [ ] `./vendor/bin/phpunit` يمرّ بالكامل

## 5. الحدود المعروفة

- **لا يوجد تحقق بخطوتين (2FA)** في المرحلة الأولى — البنية تسمح بإضافته لاحقاً.
- **حدّ المعدّل يعتمد على قاعدة البيانات** لا على ذاكرة سريعة؛ كافٍ للحجم المتوقع.
- **`trust_proxy` معطّل افتراضياً**؛ تفعيله دون وكيل موثوق يسمح بانتحال عنوان IP
  وتجاوز حدّ المعدّل.
- **التشفير على مستوى التطبيق غير مُفعَّل** لعدم جمع أي حقل يستدعيه في هذه النسخة.
